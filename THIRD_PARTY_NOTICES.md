## Recordings

### audio-cmn, syllables set (syllabs v.2)

- Used for: The native recording of every syllable and tone
- Copyright / authors: Chen Wang 王琛 (speaker); Hugo Lopez, PLIDAM, INALCO (project management, repository, audio compression, file renaming); Nicolas Vion (recording software)
- Licence: CC-BY-SA-3.0 (https://creativecommons.org/licenses/by-sa/3.0/)
- URL: https://github.com/hugolpz/audio-cmn
- Licence evidence read: README.md of github.com/hugolpz/audio-cmn (byte-identical to the copy in the source folder): "License: CC-by-sa". The repository has no LICENSE file. The SWAC tags inside every recording: SWAC_COLL_LICENSE=CC-BY-SA-3.0, SWAC_COLL_AUTHORS="Wang Chen, Lopez Hugo, Vion Nicolas", SWAC_SPEAK_NAME="Chen Wang 王琛".
- © 2013 Wang Chen, Lopez Hugo, Vion Nicolas.
- The repository README states the licence as "CC-by-sa" with no version, and the repository has no LICENSE file. Each recording's own metadata (SWAC_COLL_LICENSE) states "CC-BY-SA-3.0".
- Changes made for this app: Trimmed to the syllable, high-pass filtered (70 Hz), levelled to a common loudness, faded in and out, and converted to mono 24 kHz MP3 at 48 kbit/s. These adapted recordings are shared under the same licence.
- Only the syllable recordings are used; the project’s separate set of HSK word recordings is not.
